# 回声日记 · v0.1 静态原型

「回声日记」是一个 AI 日记小程序的可交互静态原型。核心体验只有四步：**写 → 存 → 聊 → 回看**。你随手写下一段今天，AI「回声」读完并和你聊两句，之后还能回到时间线把这一天重新打开。

- 在线演示：https://noveceli.github.io/echo-diary-demo/
- 代码仓库：https://github.com/noveceli/echo-diary-demo
- 版本：v0.1 · 更新于 2026-10-28

> 本项目是产品原型，不是生产应用。没有后端、没有真实 AI，全部数据均为预设的虚拟数据。

---

## 一、项目概览

| 项目 | 说明 |
| --- | --- |
| 形态 | 手机端网页原型（390 × 844 设备外框） |
| 技术 | 原生 HTML + CSS + JavaScript，无框架、无构建 |
| 运行方式 | 双击 `index.html` 即可离线打开，也可部署为静态站点 |
| 数据 | `mock.js` 内置 5 篇往期日记与 Stub API |
| AI | 预设话术 + 基于日记日期/原文的条件回复，不调用真实模型 |
| 演示时间 | 固定为 `2026-10-27 21:48`（今天 = 2026-10-27） |

## 二、核心流程与界面清单

### 最短通关路径

```
写  ──►  存  ──►  聊  ──►  回看
写日记    保存成功    回声对话    时间线 / 日记详情
```

| # | 界面 | 文件内标识 | 对应步骤 | 说明 |
| --- | --- | --- | --- | --- |
| 01 | 时间线首页 | `data-screen="home"` | 起点 / 步骤 4 | 日历选日、当天卡片、回声时间线、搜索占位 |
| 02 | 写日记 | `data-screen="write"` | 步骤 1 · 写 | 自动带日期与时间，可加插画/视频链接/动图 |
| 03 | 保存成功 | `data-screen="saved"` | 步骤 2 · 存 | 展示归档时间、正文摘录、附件、AI 已读提示 |
| 04 | 回声对话 | `data-screen="chat"` | 步骤 3 · 聊 | 引用日记原文与日期，两轮后引导回时间线 |
| 05 | 日记回看 | `data-screen="detail"` | 步骤 4 · 回看 | 完整正文、附件、回声回响，可再次进入对话 |

### 各步骤验收要点

1. **写**：首页点 `+` 或空状态按钮进入写日记；日期、星期、时间自动填好。
2. **存**：内容非空才能保存；保存后进入成功页，显示「日记已收好」和归档信息。
3. **聊**：成功页点「和 AI 聊聊」，AI 引用这一篇的日期与原文追问感受；连续两轮后出现「回到时间线」。
4. **回看**：回到首页能看到当天卡片与时间线记录，点开可查看正文、附件与 AI 回响。

## 三、已实现功能

### 1. 时间线首页
- 2026 年 10 月日历，含农历/节日小字、记录圆点、今天高亮。
- 点击日期切换下方「当天面板」：有记录显示日记卡片，无记录显示空状态与写作按钮。
- 未来日期不可选，点击提示「还没到这一天，先写今天吧」。
- 底部「回声时间线」按日期倒序列出全部日记。
- 首页搜索条为 P1 占位，点击只提示，不写入数据。

### 2. 年月切换
- 点击顶部「2026年10月 ⌄」打开「选择年月」面板。
- 年份可在 2020–2026 之间切换，月份 4 × 3 排列。
- 2026 年 10 月之后的未来月份不可选；过去年月可直接进入并补写日记。
- 面板底部「回到今天」一键回到 2026 年 10 月 27 日。
- 从时间线打开跨月日记后，返回首页会自动定位到对应年月。

### 3. 新建与编辑日记
- 空白日期点 `+`：新建日记，标题「写日记」，按钮「保存」。
- 已有日记的日期点 `+`：进入编辑，标题「编辑日记」，正文与附件自动预填，按钮「保存修改」。
- 保存修改后成功页显示「日记已更新 / 更新归档」，首页卡片、时间线、详情同步刷新，其他日期不受影响。
- 编辑时会保留原有的 AI 回响（`echoNote`）。

### 4. 日记附件
写日记页提供三类附件，均为本地实现，不依赖外部资源：

| 类型 | 数量 | 内容 | 实现方式 |
| --- | --- | --- | --- |
| 插画 | 3 | 江边日落、河边的风、窗边的绿萝 | 内联 SVG 手绘线稿 |
| 动图 | 3 | 水面的涟漪、热汤的白气、对面楼的灯 | 内联 SVG + CSS 循环动画 |
| 视频链接 | 不限 | 任意 `http(s)://` 链接 | 仅记录与展示，不真实播放 |

- 附件以底部 Sheet 选择或输入，支持预览、移除。
- 视频链接会做格式校验，非法链接显示错误提示，并提供一条示例链接。
- 保存后附件出现在成功页（小标签）与详情页（完整卡片）；首页日记卡片显示附件数量。

### 5. 回声对话
- 今日日记：引用当天日期与原文，追问感受；用户回复后补充昨天 10/26 那一篇。
- 往期日记：能感知「今天是否已经写过」，并据此给出不同回应。
- 详情页会保存 AI 回响，再次打开仍能看到。
- 对话来源可回溯：成功页 → 对话 → 返回成功页；详情 → 对话 → 返回详情；首页 → 对话 → 返回首页。

### 6. 其他
- 左侧演示说明栏：4 步流程高亮、5 屏快捷跳转、重置演示。
- 「重置演示」恢复初始 mock 数据、回到今天。
- 响应式：≤1120px 隐藏左侧说明栏；≤520px 全屏铺满。
- 基础可访问性：按钮 `aria-label`、日期 `aria-pressed`、面板 `role="dialog"`、Esc 关闭面板。

## 五、技术实现

### 页面与导航
- SPA 结构：5 个 `<section class="screen">` 绝对定位堆叠，`.is-active` 控制显示。
- `navigate(name, options)` 统一处理页面切换、滚动复位、步骤高亮。
- 所有页面在同一 HTML 内，无刷新跳转。

### 状态与数据
`app.js` 使用一个集中式 `state` 对象：

```js
{
  entries: [],          // 日记列表
  selectedDate,         // 当前选中日期 YYYY-MM-DD
  viewYear, viewMonth,  // 日历当前年月
  currentEntryId,       // 当前日记
  editingId,            // 编辑中的日记 id（新建时为 null）
  draftMedia: [],       // 写日记页的附件草稿
  draft: { date, time },
  chat: { origin, turn, busy, ctaShown, messages }
}
```

单篇日记的数据结构：

```js
{
  id: "e-2026-10-14",
  date: "2026-10-14",
  time: "21:02",
  text: "日记正文",
  echoNote: "AI 回声留下的话",
  media: [
    { type: "art",   key: "river-wind", title: "河边的风" },
    { type: "gif",   key: "ripple",     title: "水面的涟漪" },
    { type: "video", url: "https://...", title: "视频来源" }
  ]
}
```

### Stub API
`mock.js` 中的 `EchoAPI` 用 `setTimeout` 模拟网络延迟：

- `fetchEntries()`：返回 mock 日记
- `saveDiary({ id, date, time, text, media })`：返回组装好的 entry
- `askEcho(payload)`：返回预设对话结果

代码中保留后续接入微信云开发数据库与豆包大模型的 TODO 位置。

### 设计系统
| 令牌 | 值 | 用途 |
| --- | --- | --- |
| `--bg-app` | `#FAFAF7` | 应用底色（暖纸白） |
| `--bg-page` | `#F0EDE5` | 页面背景 |
| `--primary` | `#4FB3B2` | 主色（青绿） |
| `--primary-deep` | `#389A99` | 主色深 |
| `--primary-soft` | `#E7F4F3` | 主色浅底 |
| `--ink` | `#2E3332` | 正文墨色 |

- 标题：`Songti SC / STSong / SimSun` 衬线，字距略宽。
- 正文：`PingFang SC / Microsoft YaHei`。
- 图标与插画：全部内联 SVG，无外部图标库与图片请求。

## 六、本地运行

### 方式一：直接打开
双击 `index.html`，用浏览器打开即可（`file://` 可正常运行）。

### 方式二：本地服务器（推荐）
在 `echo-diary-demo` 目录执行：

```bash
python -m http.server 8000
```

访问 `http://localhost:8000/`。

## 七、演示路线

1. 打开首页，日历停在 **2026 年 10 月 27 日**，当天为空。
2. 点右上角 `+`，写两三句话，可顺手加一张插画或一个动图。
3. 保存 → 成功页显示归档信息 → 点「和 AI 聊聊」。
4. 回复一两轮，点「回到时间线」。
5. 首页点今天卡片或时间线条目，回看正文、附件与 AI 回响。
6. 再点 `+`，体验「编辑日记」；保存后成功页显示「日记已更新」。
7. 点顶部月份按钮，切到 2025 年 3 月补写一篇，再用「回到今天」返回。
8. 点左侧「重置演示」可恢复初始状态。

可直接查看的往期附件：
- `10 月 03 日`：插画「江边日落」+ 视频链接
- `10 月 14 日`：插画「河边的风」+ 动图「水面的涟漪」

## 十、当前范围与已知限制

**已实现**
- P0 四步核心流程
- 年月切换、新建/编辑日记
- 插画、动图、视频链接附件
- 跨月写日记与时间线定位

**P1 占位（仅有 UI，不可用）**
- 情绪标记（写日记页 5 个心情选项）
- 日记搜索（首页搜索条）

**暂未实现**
- 提醒、导出
- 账号体系与多端同步

**原型限制**
- 数据保存在内存中，刷新页面即恢复初始 mock 数据。
- 演示时间固定为 2026-10-27 21:48，不会跟随真实时间。
- 动图为 CSS 循环动画，不是 GIF 文件。
- 视频链接只做记录与展示，不嵌入播放器。
- 没有真实后端与 AI，对话内容为预设逻辑。
